Report:
In this project, I explored several variations of models in k-folds and found the best one.
I experimented with differing numbers of descent repetitions, removing weights with varying thresholds, and using regularization.
I found that a reasonable number of descent repetitions was 1000(from error curve), that regularization was helpful for improving performance,
and that removing weights below 0.01 did not significantly decrease performance(meaning we can cut those features!).
This system should be able to detect cancer in 99.439% of patients who have it(recall).
The precision is 98.066% though, which may be low for medical applications as false diagnoses are terrible for patients.
If that is an acceptable precision though, this system is ready for use in the real world.
I would like to improve this system by gathering more samples as there are only a few hundered in this dataset and more would be able to help improve the model.
One benefit of this model is that two features were found to be unnecessary and thus don't need to be collected from patients.
